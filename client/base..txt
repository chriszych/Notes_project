🧭 1. Architektura projektu (wysoki poziom)
Twoja aplikacja to klasyczny układ:

Frontend (React)
UI do logowania, rejestracji, przeglądania i edycji notatek

komunikacja z API przez fetch/axios

zarządzanie stanem (Context API lub Redux)

routing (React Router)

Backend (Node + Express)
REST API

logowanie, rejestracja, sesje lub JWT

operacje CRUD na notatkach

walidacja danych

middleware autoryzacji

Baza danych (PostgreSQL)
tabele: users, notes

relacja: user → notes (1:N)

migracje (opcjonalnie: Prisma / Sequelize / Knex)

1.5. Endpoints (REST API)
Auth

Notes
